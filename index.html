Folio

Gabung, pisah, dan putar halaman PDF, atau ubah gambar jadi PDF.

File Anda tidak diunggah, semua diproses di browser

Gabung PDF

Satukan beberapa PDF menjadi satu file.

1Pilih file
2Atur urutan (urutan di daftar = urutan di hasil)
    3Nama file dan unduh
    .pdf ditambahkan otomatis.

    Pisah halaman

    Ambil halaman tertentu jadi PDF baru, atau buang halaman yang tidak perlu.

    1Pilih file
      2Tentukan halaman
      Kosongkan kolom "Ke" untuk satu halaman saja.
      3Nama file dan unduh
      .pdf ditambahkan otomatis. Kalau terpisah, tiap file diberi akhiran halaman, misalnya nama-hlm2-4.

      Putar halaman

      Putar semua halaman, atau hanya halaman yang Anda tentukan.

      1Pilih file
        2Atur putaran
        Contoh: 2, 4-6
        3Nama file dan unduh
        .pdf ditambahkan otomatis.

        Kompres PDF

        Perkecil ukuran PDF supaya mudah dikirim lewat WhatsApp atau email.

        1Pilih file
          2Pilih tingkat kompres
          Halaman diubah menjadi gambar, jadi teks tidak bisa lagi dipilih, disalin, atau dicari.
          3Nama file dan unduh
          .pdf ditambahkan otomatis.

          Gambar ke PDF

          Satu gambar jadi satu halaman, sesuai urutan daftar.

          1Pilih gambar
            2Pilih ukuran halaman
            Berlaku untuk ukuran A4.
            Asli menjaga kualitas penuh, tapi file PDF bisa sangat besar.
            3Nama file dan unduh
            .pdf ditambahkan otomatis.

            PDF ke gambar

            Ubah halaman PDF menjadi JPG atau PNG. Banyak halaman diunduh sebagai satu ZIP.

            1Pilih file
              2Pilih halaman dan format
              Resolusi tinggi dan banyak halaman butuh memori besar di HP.
              3Nama file dan unduh
              Dipakai untuk nama ZIP. .zip ditambahkan otomatis.
