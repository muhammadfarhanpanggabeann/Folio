Gabung PDF

Satukan beberapa PDF menjadi satu file.

1Pilih file
2Atur urutan (urutan di daftar = urutan di hasil)
    3Nama file dan unduh
    .pdf ditambahkan otomatis.

    Pisah halaman

    Ambil halaman tertentu jadi PDF baru, atau buang halaman yang tidak perlu.

    1Pilih file
      2Tentukan halaman
      Kosongkan kolom "Ke" untuk satu halaman saja.
      3Nama file dan unduh
      .pdf ditambahkan otomatis. Kalau terpisah, tiap file diberi akhiran halaman, misalnya nama-hlm2-4.

      Putar halaman

      Putar semua halaman, atau hanya halaman yang Anda tentukan.

      1Pilih file
        2Atur putaran
        Contoh: 2, 4-6
        3Nama file dan unduh
        .pdf ditambahkan otomatis.

        Kompres PDF

        Perkecil ukuran PDF supaya mudah dikirim lewat WhatsApp atau email.

        1Pilih file
          2Pilih tingkat kompres
          Halaman diubah menjadi gambar, jadi teks tidak bisa lagi dipilih, disalin, atau dicari.
          3Nama file dan unduh
          .pdf ditambahkan otomatis.

          Gambar ke PDF

          Satu gambar jadi satu halaman, sesuai urutan daftar.

          1Pilih gambar
            2Pilih ukuran halaman
            Berlaku untuk ukuran A4.
            Asli menjaga kualitas penuh, tapi file PDF bisa sangat besar.
            3Nama file dan unduh
            .pdf ditambahkan otomatis.

            PDF ke gambar

            Ubah halaman PDF menjadi JPG atau PNG. Banyak halaman diunduh sebagai satu ZIP.

            1Pilih file
              2Pilih halaman dan format
              Resolusi tinggi dan banyak halaman butuh memori besar di HP.
              3Nama file dan unduh
              Dipakai untuk nama ZIP. .zip ditambahkan otomatis.

              Susun halaman

              Ubah urutan, putar, hapus, gandakan, atau sisipkan halaman kosong dalam satu layar.

              1Pilih file
                2Ketuk halaman untuk memilih. Geser ⋮⋮ untuk memindah
                3Nama file dan unduh
                .pdf ditambahkan otomatis.

                Gabung scan dua sisi

                Scanner tanpa dua sisi otomatis? Pindai semua sisi depan, balik tumpukan, lalu pindai sisi belakang. Folio menyusunnya menjadi satu PDF: depan 1, belakang 1, depan 2, belakang 2, dan seterusnya.

                1Pilih hasil pindai
                    2Atur urutan
                    Cek contoh urutan di bawah. Kalau hasilnya tidak cocok dengan kertasmu, ganti pilihan ini.
                    3Nama file dan unduh
                    .pdf ditambahkan otomatis.

                    Watermark dan nomor halaman

                    Pasang tulisan seperti RAHASIA atau SALINAN, dan beri nomor di tiap halaman.

                    1Pilih file
                      2Pilih yang dipasang
                      Hanya huruf Latin (A–Z dan aksen Eropa). Huruf Arab, Mandarin, dan lainnya belum didukung.
                      Contoh: 1-3, 5
                      Angka untuk halaman pertama yang diberi nomor.
                      Contoh: 2-10. Nomor dihitung dari halaman pertama dalam rentang ini.
                      3Nama file dan unduh
                      .pdf ditambahkan otomatis.
